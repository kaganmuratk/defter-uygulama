# Antrenör defteri (uygulama kabuğu)

iPad/iPhone için yerel çalışan öğrenme uygulaması (Capacitor). **Bu depoda içerik yoktur:** part metinleri ve kitap görselleri
özel bir sunucudan, uygulamaya girilen anahtarla indirilir ve cihaza kaydedilir. Depo bu yüzden herkese açıktır ve macOS derlemesi ücretsizdir.

- Derleme: GitHub Actions > "IPA" (imzasız IPA üretir; iLoader / SideStore ile imzalanıp kurulur).
- İçerik ve senkron: ayrı, özel bir Cloudflare Worker (bu depoda değil).
